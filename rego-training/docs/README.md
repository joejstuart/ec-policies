# Rego Training Documentation

This directory contains documentation for the Rego policy training system.

## Organization

### Training Documentation (`training/`)
- **FINETUNING.md** - Guide for fine-tuning Qwen3 models
- **QUICK_START.md** - Quick start guide
- **INSTRUCTION_VARIATION_PLAN.md** - Plan for training on instruction variations
- **VARIATION_TRAINING_WORKFLOW.md** - Workflow for generating and using variations
- **TEST_CREATION_TRAINING.md** - Guide for training on test creation
- **SEQUENCE_LENGTH_ANALYSIS.md** - Analysis of training data sequence lengths

### Deployment Documentation (`deployment/`)
- **OLLAMA_DEPLOYMENT_PLAN.md** - Plan for deploying to Ollama
- **OLLAMA_NEXT_STEPS.md** - Step-by-step Ollama deployment guide
- **INFERENCE_EXAMPLES.md** - Examples for using the inference script

### Troubleshooting (`troubleshooting/`)
- **MEMORY_OPTIMIZATION.md** - Solutions for CUDA out of memory errors
- **INSTALLATION.md** - Installation guide and dependency conflict resolution
- **GGUF_CONVERSION_TROUBLESHOOTING.md** - Troubleshooting GGUF conversion issues

### Other Documentation
- **VALIDATION_TEST_GENERATION.md** - Guide for validation test generation
- **TEST_CASES_COVERAGE.md** - Test case coverage documentation
- **validation_report.md** - Training data validation report
- **attestation-structure-training-data.md** - Attestation structure reference
- **TRAINING_DATA_GENERATION_PLAN.md** - Plan for training data generation
